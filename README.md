# RecordTemperature

ネットワークカメラ (Tapo TC70) で撮影したデジタル温湿度計（7セグ表示）を OpenCV で読み取り、
1分おきに温度・湿度を記録して、ブラウザでグラフ・表を閲覧できる Windows 常駐アプリです。

- 複数カメラ対応（1カメラにつき温湿度計1台：温度・湿度の2値）
- 校正は半自動：表示部の四隅をクリック → 桁位置・極性・傾きは自動推定 → 実際の表示値を入力すると閾値等を自動探索
- カメラの小さなずれは基準画像との位置合わせ (ECC) で自動補正
- 範囲外・急変・低信頼の読み取りは除外し、画像付きで「読取確認」画面に表示 → 手入力で修正するとサンプルとして再校正に利用
- PC 起動（ログオン）時・スリープ復帰時に自動で記録を再開

## セットアップ

Python 3.11 以上が必要です。

```powershell
cd Y:\Documents\OriginalProjects\RecordTemperature
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -e .[dev]
```

### Tapo カメラ側の準備

1. Tapo アプリ → 対象カメラ → 設定 → 高度な設定 → **カメラのアカウント** でユーザー名/パスワードを作成
   （TP-Link ID とは別物です）
2. カメラの IP アドレスを確認（ルーターで固定 IP / DHCP 予約にしておくことを推奨）
3. RTSP URL は `rtsp://ユーザー名:パスワード@IP:554/stream1`（アプリが自動で組み立てます）

## 起動

```powershell
.venv\Scripts\python -m recordtemp --open      # コンソール付き（動作確認用）
.venv\Scripts\pythonw -m recordtemp            # ウィンドウなしで常駐（タスクトレイにアイコン）
```

ブラウザで <http://127.0.0.1:8765/> を開きます。タスクトレイのアイコンから「ブラウザで開く」「今すぐ撮影」「終了」ができます。

オプション: `--no-tray`（トレイアイコンなし） / `--port 8765` / `--open`（起動時にブラウザを開く）

### 自動起動（PC起動時・スリープ復帰時）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_autostart.ps1
Start-ScheduledTask -TaskName RecordTemperature   # すぐ起動する場合
```

タスクスケジューラに次のトリガーで登録します（管理者権限不要）。

| トリガー | 内容 |
|---|---|
| ログオン時 (30秒遅延) | PC 起動・サインイン後に常駐開始 |
| スリープ復帰イベント (Power-Troubleshooter ID 1, 20秒遅延) | プロセスが終了していた場合の保険 |

常駐中のプロセスはスリープから復帰すると、壁時計基準のスケジューラが遅延を検知して**即座に撮影を再開**します
（スリープ中の記録は欠損として扱い、グラフでは線が途切れます）。復帰直後はネットワーク接続が戻っていないことがあるため、
撮影失敗時は数秒おきにリトライします。二重起動は名前付きミューテックスで防止しています。

解除: `powershell -ExecutionPolicy Bypass -File scripts\uninstall_autostart.ps1`

## 使い方

1. **カメラ・校正** → 「カメラを追加」で IP・カメラアカウントを入力し「接続テスト」
2. **校正**画面
   1. 「カメラで撮影」
   2. 温度・湿度それぞれの **数字部分**（℃・% 記号は含めない）の四隅をクリック。桁数と小数点以下桁数を入力
      - 温度で `-5.2` のようにマイナスが出る機種は、マイナス用の桁を含めた桁数にします（例 `23.5` 表示なら 3 桁）
   3. 「自動認識」→ 桁枠（水色）・点灯セグメント（緑）を確認。ずれていれば枠をドラッグで調整
   4. 温湿度計に実際に表示されている値を入力し「正解値に合わせて自動調整」
   5. 「校正を保存」
3. **ダッシュボード**で最新値とグラフ（温度・湿度・絶対湿度、1時間〜30日・期間指定、複数カメラ重ね表示）、**記録一覧**で表と CSV 出力
   - ダッシュボード下部の**快適温湿度チャート**（横軸=湿度・縦軸=温度）に、同じ期間の記録を点で表示します。PMV（ISO 7730）等値線・快適域・絶対湿度 7/11g/m³ の線・カビ/ダニの目安範囲を背景に描画します
   - 温度・湿度グラフには**外気（気象庁アメダス）**を破線で重ねて表示します。既定は中野区に最寄りで湿度も観測している練馬（44071）。10分ごとに取得し、初回は過去約9日分をさかのぼります。観測所番号は設定画面で変更できます
   - 記録一覧の「修正」で、確定済みの温度・湿度をあとから手で修正できます（状態は「手入力」になり、✎印が付きます）
   - 修正前の自動記録値は保持され、「元に戻す」でいつでも復元できます。CSV にも修正前の値の列が出力されます
4. **読取確認**に失敗した記録が画像付きで並ぶので、正しい値を入力して修正。
   サンプルが溜まったら校正画面の「全サンプルで再調整して保存」で精度を改善できます

### 読み取りのコツ

- カメラは温湿度計の正面に近い位置で、表示部が画面の 1/5 程度以上の大きさに写るように設置
- 照明の映り込み（反射）が数字にかからないように角度を調整
- 夜間（赤外線モード）でも読めるか、夜に一度「読取確認」画面で確認してください。読めない場合は夜間の画像でもサンプルを追加して再調整します

## 7セグ認識の仕組み

```
フレーム ─(基準画像とのECC位置合わせで四隅を補正)→ 射影変換で表示部を正面化
 → 極性に応じて「セグメントが明るい」画像に変換 → トップハットで照明ムラ除去
 → シアー変換で斜体を補正（横方向勾配の投影が最も鋭くなる角度を自動推定）
 → Otsu + オフセットで二値化 → 各桁枠で7セグメント領域の塗りつぶし率を測定 → パターン表で数字化
 → 小数点位置は設定から付与 → 範囲・急変・信頼度チェック
```

校正の自動調整は、極性 × 傾き × 閾値オフセット × セグメント幅 × 点灯判定閾値をグリッド探索し、
正解値つきサンプルの一致数が最大（同数なら平均信頼度が最大）となるパラメータを選びます。

## データ

すべて `data/` に保存されます（Git 管理外。環境変数 `RECORDTEMP_DATA` で変更可）。

- `recordtemp.db` … SQLite（cameras / readings / calibrations / samples / outdoor＝アメダス）
- `images/camN/` … 最新フレーム、校正用画像、失敗した読み取りの画像（既定30日で自動削除）
- `logs/recordtemp.log` … ログ
- `config.json` … 設定（Web の設定画面から変更可）

カメラのパスワードは Windows 資格情報マネージャー（`RecordTemperature` / `camera:N`）に保存され、DB には入りません。
